# 🛶 Atlanter Floating Fleet / Atlanter Schwimmende Flotte

**Prehistoric High-Culture Fleet** / **Prähistorisches Hochkultur-Flottenkonzept**
*10,000 BCE Megaplatforms* / *Megaplattformen vor 10.000 v. Chr.*

## Overview / Überblick
**EN**: Floating settlements from giant sequoias, hemp-connected fleet for 3,000–7,000 people.
**DE**: Schwimmende Siedlungen aus Mammutbäumen, Hanf-verbundene Flotte für 3.000–7.000 Personen.

| Feature / Merkmal | Single Unit / Einzelplattform | Fleet / Flotte |
|------------------|------------------------------|---------------|
| Size / Größe     | 100×50m, 4 decks / Etagen   | 5–10 units    |
| Capacity / Kapazität | 600–700 pers. (30m²/pers.) | 3.000–7.000   |
| Materials / Materialien | Sequoias, hemp, copper/bronze | Same / Gleich |

## Tech Specs / Technische Daten
- **Structure**: 10–15 trees/side + hemp nets / 10–15 Bäume + Hanfnetze
- **Decks**: Storage, hydroponics, living / Lager, Hydrokultur, Wohnen
- **Speed**: 4–6 km/h via currents / Strömung
- **Connection**: Hemp hawsers (20cm) / Hanf-Taue

## Atlanter Context / Atlanter-Kontext
Inspired by Plato's Atlantis + Göbekli Tepe logistics. Proto-hydraulics for ebb-flow gardens.
Inspiriert von Platon + Göbekli Tepe. Protohydraulik für Ebbe-Flut-Gärten.
